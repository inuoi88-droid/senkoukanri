# 選考管理

就活の選考状況を **Google スプレッドシート** で管理し、面接・締切・企業からのメールを **スマホにプッシュ通知** するアプリです。

- アプリ：**https://senkoukanri.vercel.app/**
- データは自分の Google スプレッドシートにだけ保存されます。手で直接編集しても大丈夫です
- サーバー代はかかりません（Google Apps Script とスマホの Web アプリ機能を使います）

## できること

| 機能 | 内容 |
| --- | --- |
| 選考状況の記録 | 企業ごとのステータス（エントリー済 → 一次面接 → … → 内定 / お祈り）、志望度、業界、メモ |
| マイページ | 企業ごとにマイページ URL とログイン ID を保存。アプリからワンタップで開く・コピー |
| 予定 | 面接・GD・ES 締切・Web テスト締切・説明会など。結果（通過 / 不通過 …）も記録 |
| 面接・締切前の通知 | 面接は 1 日前・3 時間前・1 時間前、締切は 3 日前・1 日前・6 時間前・1 時間前（変更可） |
| 朝のまとめ | 毎朝 8 時に「今日・明日の予定と 3 日以内の締切」を通知 |
| 結果メール確認リマインド | 面接や提出が終わって結果を記録していない選考があると、毎晩 21 時に「結果メールを確認しましたか？」と通知 |
| Gmail 検知 | 登録した企業からのメールが Gmail に届いたら **5 分以内に通知**。「確認済」にするまで 2 時間ごとに再通知 |
| 通知が届かないときの保険 | スマホへの通知が 1 台も届かなかったときは、同じ内容を Gmail に送ります |

> 「三次面接のお知らせを見逃した」を二度と起こさないために、**企業からのメールは確認済みにするまでしつこく通知** します。

## しくみ

```
スマホ（ホーム画面に追加した Web アプリ）
   │  読み書き                     ▲ プッシュ通知
   ▼                               │
Google Apps Script（ウェブアプリ） ── 5分おきに実行 ──┐
   │                                                 │ 予定・Gmail をチェック
   ▼                                                 ▼
Google スプレッドシート（データ）              Gmail（就活用アカウント）
```

## セットアップ（30 分ほど）

**必ず就活用の Google アカウント（例：kotonimukae@gmail.com）でログインした状態で作業してください。** Gmail 検知は、スプレッドシートを作ったアカウントの Gmail を見ます。

### 1. スプレッドシートを作る

1. [Google スプレッドシート](https://sheets.new) で新しいスプレッドシートを作る
2. 名前を「選考管理」などに変える

### 2. Apps Script にコードを貼る

1. スプレッドシートのメニュー **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の中身を貼り付ける
3. 左の「ファイル」の **＋ → スクリプト** で `WebPush` という名前のファイルを作り、[`gas/WebPush.gs`](gas/WebPush.gs) の中身を貼り付ける
4. 💾（保存）を押す

> GitHub でファイルを開いたら、右上の「Raw」ボタンか、コピーボタン（⧉）を使うと全文をコピーできます。

### 3. 初期設定を実行する

1. Apps Script の画面上部で、関数のプルダウンから **`setup`** を選んで **▷ 実行**
2. 「承認が必要です」→ **権限を確認** → 自分のアカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら **詳細 → 選考管理（安全ではないページ）に移動** → **許可**
   - 自分で作ったスクリプトなので問題ありません。Gmail の読み取り（企業メールの検知）と送信（通知が届かないときの保険）、外部への通信（プッシュ通知の送信）の許可を求められます
4. スプレッドシートに「企業」「予定」「メール」「設定」などのシートができていれば成功です

### 4. ウェブアプリとしてデプロイする

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 「種類の選択」の ⚙ → **ウェブアプリ**
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリの URL（…/exec）** をコピー

> 「全員」にしても、合言葉（自動生成される 64 文字のトークン）を知らない人はデータを読めません。

### 5. スマホと接続する

1. スプレッドシートを再読み込みすると、メニューに **選考管理** が出ます
2. **選考管理 → ② スマホと接続する** を開き、コピーした URL を貼り付けて「接続用 QR コードを作る」
3. スマホのカメラで QR コードを読み取る → アプリが開いて自動で接続されます
   - QR が読めないときは「リンクを自分にメールする」を押して、スマホでメールのリンクを開いてください

### 6. ホーム画面に追加して通知をオンにする

**iPhone（iOS 16.4 以降）**

1. Safari でアプリを開いた状態で、共有ボタン（□↑）→ **ホーム画面に追加**
2. ホーム画面の「選考管理」アイコンから開く
3. 接続コードを聞かれたら、手順 5 で表示された接続コード（メールにも書いてあります）を貼り付ける
4. **通知をオンにする** → 「許可」
5. 「テスト通知を送りました」のあと、通知が届けば完了 🎉

> iPhone は「ホーム画面に追加」したアプリからでないと通知を受け取れません。集中モードがオンだと通知が表示されないことがあります。

**Android（Chrome）**

1. Chrome でアプリを開き、メニュー（︙）→ **ホーム画面に追加**（または「アプリをインストール」）
2. ホーム画面のアイコンから開いて **通知をオンにする** → 「許可」

## 使い方

### 企業を登録する

右下の **＋ → 企業を追加**。マイページ URL・ログイン ID も入れておくと、企業ページの「マイページを開く」からすぐ開けます。
（パスワードは保存しないでください。パスワード管理アプリを使いましょう）

**メール検知キーワード** には、その企業のメールに必ず含まれる語をカンマ区切りで入れます。空欄なら企業名で探します。

- 例：`日本アイ・ビー・エム, ibm.com`
- 採用メールは「i-web」「HRMOS」など採用管理サービスから届くことも多いので、**実際に届いたメールの差出人や署名に書いてある会社名** を入れるのが確実です

### 予定を登録する

**＋ → 予定を追加**。種別（面接 / GD / ES締切 / Webテスト締切 / 説明会 / その他）と日時を入れると、自動で通知されます。

- ES・Web テストを出したら **「提出・受験した」** を押す → 締切の通知が止まります
- 面接などが終わったら、結果が来た時点で **通過 / 不通過** を記録 → 結果確認リマインドが止まります
  - 通過にすると次の予定の登録を、不通過にすると企業を「お祈り」にするかを聞きます
- 「お祈り」「辞退」の企業は通知・メール検知の対象外になります

### 企業からのメール

Gmail 検知で見つかったメールはホームの一番上に赤く出ます。中身を確認したら **確認済み** を押してください（押すまで 2 時間ごとに再通知します。夜 0 時〜7 時は再通知しません）。
Android は通知の「確認済みにする」ボタンからも押せます。

### スプレッドシートを直接編集する

アプリで入れた内容はすべてスプレッドシートに入っています。PC から一気に入力したいときは直接編集して OK です。

- **1 行目（見出し）の文字は変えないでください。** 列の並べ替えや、新しい列の追加は自由です
- **ID は空欄のままで OK**（次にアプリが読み込んだとき自動で付きます）
- 「予定」シートの **企業名** は「企業」シートの企業名と同じ表記にしてください（プルダウンから選べます）
- **日時** は `2026/10/15 14:00` の形で入力。日付だけだと 0:00 扱いになります
- **完了**（提出・受験済み）はチェックボックス。チェックが無い行は `TRUE` / `済` / `○` でも OK

| シート | 内容 |
| --- | --- |
| 企業 | 企業ごとの情報。ステータス・マイページ URL など |
| 予定 | 面接・締切などの予定と結果 |
| メール | Gmail 検知で見つかったメール。「確認済」にチェックで再通知が止まる |
| 設定 | 通知のタイミングなど（下の表） |
| 通知端末 | 通知を受け取るスマホ（自動で管理） |
| 通知ログ | 送った通知の記録（60 日で自動削除） |

### 設定シートの項目

| 項目 | 初期値 | 説明 |
| --- | --- | --- |
| ステータスの選択肢 | 気になる, エントリー済, … , お祈り, 辞退 | 変更後はメニュー「選考管理 → 入力規則を更新」 |
| 終了扱いのステータス | お祈り, 辞退 | この企業は通知・メール検知しない |
| 通知タイミング：面接 など | 1日前, 3時間前, 1時間前 | 「◯日前」「◯時間前」「◯分前」をカンマ区切り。空欄で通知しない |
| 朝のまとめ通知（時） | 8 | 空欄で送らない |
| 結果確認リマインド（時） | 21 | 空欄で送らない |
| 結果確認リマインドの期間（日） | 30 | 予定日から何日間リマインドするか |
| Gmail検知 | ON | OFF で無効 |
| Gmail検知：共通キーワード | （空） | 企業を問わず検知したい語（例：`選考結果, 面接のご案内`） |
| Gmail検知：除外条件 | -category:promotions … | Gmail の検索演算子。メルマガを除外 |
| 未確認メールの再通知間隔（時間） | 2 | 0 で再通知しない |
| 再通知しない時間帯 | 0-7 | 未確認メールの再通知を止める時間帯 |
| アプリのURL | https://senkoukanri.vercel.app/ | 接続用 QR コードに使う |

## 困ったとき

**通知が来ない**
1. アプリの **設定 → テスト通知を送る** を押す
2. 失敗と出る、または届かない場合は「この端末の通知をオフ」→「通知をオンにする」をやり直す
3. iPhone はホーム画面のアイコンから開いているか、端末の 設定 → 通知 → 選考管理 が許可されているかを確認
4. スプレッドシートの「通知ログ」シートで送信結果（OK / NG）を確認できます

**「サーバーに接続できませんでした」と出る**
- デプロイ設定が「実行ユーザー：自分」「アクセスできるユーザー：全員」になっているか確認してください

**Apps Script のコードを更新したとき**
- **デプロイ → デプロイを管理 → ✏️（編集）→ バージョン「新バージョン」→ デプロイ** を行ってください。URL は変わりません（「新しいデプロイ」を作ると URL が変わり、接続し直しが必要になります）

**接続コード（QR コード）を人に見られた**
- メニュー **選考管理 → 合言葉（トークン）を作り直す** を実行し、スマホで接続し直してください

**通知が多すぎる / 少なすぎる**
- 「設定」シートの通知タイミングを変えてください。次の 5 分おきのチェックから反映されます

## 開発者向け

```
app/        スマホ用の Web アプリ（PWA）。ビルド不要の HTML / CSS / JS
  sw.js     Service Worker（オフライン用キャッシュ・プッシュ通知の表示）
gas/        Google Apps Script
  Code.gs     シートの読み書き・Web API・通知スケジューラ・Gmail 検知
  WebPush.gs  Web Push の暗号処理（VAPID / aes128gcm）を純粋な JS で実装
test/       テスト（Node.js 上で偽のスプレッドシートを使って Code.gs を動かす）
```

```bash
npm install
npm test            # GAS のロジック・暗号処理のテスト
npm run test:e2e    # ブラウザでアプリを操作する E2E テスト（Playwright）
npm run serve       # http://localhost:8080 でアプリを表示
```

- Web Push の暗号化は RFC 8291（aes128gcm）、送信者認証は RFC 8292（VAPID / ES256）。Apps Script には WebCrypto が無いため、P-256・AES-GCM・SHA-256 を `gas/WebPush.gs` に実装しています。出力は Node の `http_ece`（`web-push` ライブラリが使っているもの）とバイト単位で一致することをテストで確認しています
- アプリ本体（`app/`）は静的ファイルだけなので、HTTPS で配信できる場所ならどこでも動きます。現在は Vercel プロジェクト `senkoukanri`（ルートディレクトリ `app`、ビルドなし）で https://senkoukanri.vercel.app/ に公開しています。GitHub と連携済みなので、`main` ブランチに入った変更は自動で本番に反映されます
- アプリのファイルを変えたら `app/sw.js` の `VERSION` も上げてください（スマホに古いキャッシュが残らないように）
